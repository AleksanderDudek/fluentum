# Fluentum — plan

**Status (2026-10-02): in progress.**

Owner request (2026-10-02): language sessions become a separate application; Teleo stays focused on prayers,
affirmations and memorising sentences. The new app's name should draw on languages and on motivation / tracking
progress, and the app should be free. "Create another repo and remove language sessions or its traces from this repo.
Analyse the current system, use best practices, pick recommended. Plan it out and then finish on your own."

## Analysis

- **What moves.** Teleo's language dialogues (Teleo DECISIONS #101–#108): scripted bilingual conversations, the chat
  player, word links by grammatical role, pronunciation respellings, `learningLang`. They sit on Teleo's engine: speech
  engines (Web Speech, offline Whisper), the matcher and coverage ladder, the live tracker, the practice service (one
  transaction per attempt: XP, streaks, freezes, goal, golden quarter-hour, achievements), backups, the PWA shell.
- **Extraction strategy.** Monorepo with a shared engine package → rejected: two small static apps, one owner, no
  publishing pipeline; a shared package would add build/versioning machinery and couple releases of an app with live
  users to an app that does not exist yet. **Recommended: a new repository started from a snapshot of Teleo
  (af2b337), then stripped and rebranded** — the engine is mature and tested; each app evolves on its own. History
  starts fresh (Teleo's history is about prayers; the first commit names the source commit).
- **Same origin.** Both apps live on `aleksanderdudek.github.io` (`/teleo/`, `/fluentum/`) — one browser origin. So:
  IndexedDB name `fluentum`, Cache Storage names `fluentum-*`, a separate transformers.js cache for Whisper models,
  service worker scope `/fluentum/`, no shared `localStorage` keys. Neither app may touch the other's data.
- **Free.** Like Teleo: no accounts, no backend, no paid services, no API keys, no ads, no analytics; an optional
  "buy a coffee" support link.

## Name — Fluentum

*Fluent* (languages) + *momentum* (motivation, progress that keeps going); *fluentum* is also Latin for "flowing" —
a sibling to Teleo's Greek *telos*. Reads naturally in Polish and English. Checked 2026-10-02: no language app of that
name found; npm `fluentum` and `github.com/AleksanderDudek/fluentum` are free. Tagline: "Speak a new language — one
conversation a day." / „Mów w nowym języku — jedna rozmowa dziennie.”

## Decisions (recommended)

1. **Product.** Polish speakers learn English, English speakers learn Polish (the interface language is the native one;
   the other is learnt). A course of short everyday conversations (A1–A2): the partner speaks first (synthesised voice
   in the target language), the learner answers aloud and every line is checked by the matcher. Word links coloured by
   grammatical role, pronunciation spelt the learner's way. Content keyed by language, so a third language needs content
   and matcher support, not a new engine.
2. **Mastery — three ways through every conversation, one star each.** *Read* (the line, its pronunciation and
   meaning), *Prompt* (only the first letters of each word plus the meaning), *Recall* (only the meaning: say it from
   memory). Words reveal as they are heard. A star is earned by finishing the conversation in that way with every line
   said (no skips) and no line revealed with "Show"; the first time a star is earned gives bonus XP. Modes are never
   locked; the next one is recommended. This turns reading aloud into recall practice — the core of learning to speak.
3. **Motivation and progress.** Kept from Teleo: XP and levels, daily goal (lines per day), streak with freezes,
   golden quarter-hour, combos and chime, achievements, heatmap, personal and friends' leaderboard (cards in links,
   no server), shareable day/conversation cards, calendar reminder (.ics). New: stars per conversation, course progress
   by level, language-specific achievements (conversations, stars, mastered, level A1/A2 complete, flawless).
4. **Data model.** Fresh Dexie database `fluentum` v1 (no migrations to carry). The engine's run model stays — a
   conversation is a hidden text `dialogue:<lang>:<key>` holding the learner's lines as segments, played as a run — but
   everything prayer-specific goes: no text types, tags, archive flags, split modes, builtin seeding, session
   templates, memory levels of texts, Bible tables, per-text achievement rules. `TextStats` gains `stars` (0–3).
   Runs carry `mode: 'read' | 'prompt' | 'recall'`.
5. **Screens.** Tabs: **Home** (greeting, streak, goal, golden quarter-hour, "continue" — the next recommended
   conversation and way), **Conversations** (the course by level, stars), **Progress**, **Settings**. A conversation
   page (scene, partner, stars, the three ways). Chat player, summary ("next conversation"), onboarding (welcome with the
   language pair, character, microphone, goal), mic test, your data (backups), friend invitations.
6. **Identity.** Not the gilded icon (devotional imagery has no place here). A "flow" palette: deep teal (action,
   flowing water), coral (the live voice, the streak flame), gold (earned: XP, stars), cool paper; dark theme
   "Night swim". Type: Lexend (designed to improve reading fluency) for headings and spoken lines, Instrument Sans for
   UI. Icons: Phosphor Duotone only (generated paths, no Teleo Glyphs). The cast is redrawn as modern flat portraits
   (same eight names); the guide is **Lori**, a lorikeet — parrots repeat words aloud — drawn in code.
7. **Content.** The eight Teleo conversations plus eight new ones (16): bakery, taxi, weather, pharmacy, clothes,
   booking a table, airport, birthday. Same validation test (markup, links, respellings, matcher accepts each line).
8. **Licence and docs.** All rights reserved like Teleo (owner's choice). `docs/FLUENTUM_SPEC.md` is the source of
   truth; `docs/DECISIONS.md` carries the engine decisions that still apply (renumbered) and the new ones; README,
   CHANGELOG, CLAUDE.md, privacy page.
9. **Publishing.** Nothing is pushed or created on GitHub automatically (Teleo DECISIONS #9): the repository is
   local; README lists the two commands that publish it. CI and Pages workflows are ready.
